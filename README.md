# Лабораторная работа №2, вариант 6

Перемножение двух матриц комплексных чисел на Си с использованием потоков POSIX Threads в Linux. Вся реализация находится в `main.c`.

Все команды выполняются из папки проекта `OC_Lab2`.

## Сборка

```bash
gcc -std=c99 -Wall -Wextra -Wpedantic -Werror main.c -o main -lm
```

## Параметры

```text
./main N
```

`N` — положительное целое число, ограничивающее общее количество потоков процесса, включая основной. Например, при `./main 4` используются основной и до трёх дополнительных потоков. Основной поток тоже вычисляет свои строки. Если строк результата меньше `N`, количество потоков уменьшается до числа строк. При `./main 1` дополнительные потоки не создаются.

## Ввод

Сначала введите размеры первой матрицы A: число строк и число столбцов. Затем введите все её элементы по строкам. После этого введите размеры второй матрицы B и все её элементы. Количество столбцов A должно совпадать с количеством строк B. Все размеры положительные.

Для каждого комплексного числа вводятся два конечных вещественных числа: действительная и мнимая части. Например, `3 -2` означает `3-2i`. Элементы перечисляются по строкам, дробная часть отделяется точкой. Программа объясняет эту схему один раз, перед вводом первой матрицы.

### Пример 1: матрицы 2×2, один поток

Запуск:

```bash
./main 1
```

Полный ввод (его можно вставить в терминал целиком):

```text
2 2
1 1  2 0
3 0  0 1
2 2
1 0  0 1
2 0  1 0
```

Ожидаемая матрица:

```text
(5+1i) (1+1i)
(3+2i) (0+4i)
```

Вычисления выполняет один основной поток.

### Пример 2: матрицы 3×2 и 2×2, два потока

Запуск:

```bash
./main 2
```

Полный ввод:

```text
3 2
1 1  2 0
0 1  -1 0
3 0  2 -1
2 2
1 0  0 1
2 -1  1 0
```

Здесь A имеет строки `(1+i, 2)`, `(i, -1)`, `(3, 2-i)`. Матрица B имеет строки `(1, i)`, `(2-i, 1)`.

Ожидаемая матрица результата размером 3×2:

```text
(5-1i) (1+1i)
(-2+2i) (-2+0i)
(6-4i) (2+2i)
```

Дополнительный поток вычислит первые две строки, основной — третью.

В обоих примерах программа выводит две подсказки ввода, время умножения и матрицу результата. Время меняется от запуска к запуску.

### Ввод из файла

Можно сохранить ввод в `input.txt` и запускать программу так:

```bash
./main 4 < input.txt
```

Если сохранить ввод из первого примера, будут использованы два потока, поскольку у результата две строки.

## Распределение работы

`multiply_rows()` вычисляет строки с номером `start_row` включительно до `end_row` исключительно.

В `multiply_parallel()` строки распределяются как можно равномернее. Например, для восьми строк и трёх потоков получаются диапазоны `[0, 3)`, `[3, 6)`, `[6, 8)`.

Дополнительные потоки запускаются через `pthread_create()`, основной вычисляет последний диапазон. Затем основной вызывает `pthread_join()` для каждого созданного потока.

Исходные матрицы во время умножения только читаются. Каждый элемент результата записывает один поток. Поэтому взаимное исключение при записи элементов не требуется; вывод результата и освобождение памяти происходят после завершения всех вычисляющих потоков.

При ошибке создания потока программа дожидается уже созданных потоков и завершает работу с ошибкой, не выводя частичный результат.

## Просмотр потоков средствами ОС

Для достаточно больших матриц можно запустить программу в фоне и получить PID средствами оболочки:

```bash
./main 4 < input.txt > output.txt &
program_pid=$!
ps -L -p "$program_pid" -o pid,tid,stat,comm
ps -p "$program_pid" -o pid,nlwp,comm
wait "$program_pid"
```

Ввод берётся из `input.txt`, вывод сохраняется в `output.txt`. `program_pid` содержит PID запущенной программы. `TID` — идентификатор потока, `NLWP` — количество потоков процесса в момент наблюдения. На маленьком примере программа может завершиться раньше проверки. Число потоков может уменьшаться к концу вычисления, когда потоки завершают свои диапазоны.

## Измерения для отчёта

Время измеряется через `CLOCK_MONOTONIC`. Измеряемый участок включает подготовку задач, создание потоков, умножение и ожидание завершения. Ввод, выделение памяти для матриц, вывод результата и освобождение памяти матриц находятся за пределами измеряемого участка.

Для сравнения запускайте одни и те же входные данные с разными пределами потоков:

```bash
./main 1 < input.txt > result1.txt
./main 2 < input.txt > result2.txt
./main 4 < input.txt > result4.txt
```

В каждом файле результата будет строка со временем умножения.

Повторите каждый замер несколько раз и сравните медианы. Исследуйте разные размеры матриц. Ускорение: `S(p) = T(1) / T(p)`. Эффективность: `E(p) = S(p) / p`, где `p` — фактически выбранное программой количество потоков, включая основной. На маленьких матрицах расходы на создание потоков могут превышать выигрыш от параллельных вычислений.

Элементы и результат представлены типом `double`: вычисления имеют обычную погрешность вещественной арифметики и ограниченный диапазон значений. Матрицы целиком находятся в оперативной памяти.
